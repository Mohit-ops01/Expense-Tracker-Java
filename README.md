# Personal Expense Tracker (Java)

## Description
A console-based Personal Expense Tracker application developed using Core Java.
The application allows users to record daily expenses and store them using file handling so that data is retained even after the program exits.

## Features
- Add new expense records
- View all saved expenses
- Delete an expense by selection
- Calculate total expenses
- Filter expenses by category
- Persistent storage using text files

## Technologies Used
- Java (Core)
- File Handling
- OOP Concepts
- ArrayList
- Scanner

## How to Run
1. Clone the repository
2. Open the project in IntelliJ IDEA
3. Run the `Main.java` file

## Learning Outcome
This project helped in understanding Java file handling, object-oriented programming, and basic data management logic.
